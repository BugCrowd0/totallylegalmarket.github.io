TOTALLYLEGALMARKET WEBSITE
===========================

Files:
- index.html
- style.css
- script.js
- assets/logo.png

Open index.html in your browser to preview the site.

To customize:
- Edit the text/content in index.html.
- Edit colors/layout in style.css.
- Replace assets/logo.png with another logo using the same filename.
- Replace the sample market cards with your own items/links.

This is a static HTML/CSS/JS site and does not require a backend.
